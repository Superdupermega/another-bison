Method

Frame. Specify. Prove. Verify.

Our method is built on one test: an autonomous coding agent must be able to implement the specification without asking a single clarifying question. If it has to ask, the spec is the bug.

Principles

Intent is the source code

Implementation is generated and regenerated. The spec is what humans author, review, and version. We treat it with the rigour code used to get.

Every constraint has an enforcement point

"The model should never…" is a wish. A constraint names the middleware, router, schema, or test that makes violation impossible or detectable.

Non-determinism stops at the boundary

Models propose; deterministic systems dispose. Every model output passes through schema validation, policy checks, and a transactional boundary before it touches state.

Evidence over assurance

We do not say a system is safe. We show the property tests, the probe results, and the telemetry, and name the human who signed off on the residual risk.

The four phases

Frame · days 1–2

Workshop with the accountable decision owner. Output: outcome statement, objective function with priorities and hard floors, decision class and risk tolerance, do-not-build list. We refuse to proceed without a named accountable role.

Specify · days 3–7

Constraints with enforcement points and verification references. Edge-case table. Interface and data contracts with freshness and provenance. Acceptance tests as executable statements. The spec passes BIS-lint before anyone writes code.

Prove · days 8–11

Autonomous agents implement from the spec in a clean environment. Every clarifying question the agent raises is logged as a spec defect and fixed upstream. The reference implementation is a by-product; the hardened spec is the deliverable.

Verify · days 12–14

Property-based tests against every objective, constraint, and edge case. Security probes on model-exposed surfaces. Telemetry wired to hard floors so a breach is an incident, not a dashboard trend. Evidence table filled and signed.

Most agentic systems we design reduce to this shape. Autonomy lives in the middle; everything at the edges is deterministic and auditable.

Fallback loops we always build

Halt

Agent produces no output within budget. Route: retry with a smaller model once, then queue for human, never auto-complete.

Drift

Agent output diverges from the objective function (measured by a deterministic scorer). Route: reset context to last checkpoint, re-plan, escalate on second drift.

Malformed

Output fails schema. Route: one structured repair attempt, then fail closed with a typed error the caller must handle.

Disagreement

Consensus agents disagree beyond threshold. Route: tie-break by pre-declared rule (conservative option wins) or human.

Provider failure

Model unavailable or degraded. Route: multi-vendor failover with equivalence tests, then graceful degradation to non-AI path.

Budget breach

Cost or latency envelope exceeded. Route: hard stop, incident, never silently continue.
